Privacy

Last updated 17 September 2026.

The short version

The text you paste into this site is never uploaded, never stored and never seen by anyone else.

What happens to the text you paste

All processing happens inside your own web browser, on your own device. The text you paste is read by code running locally on your machine, and the result is displayed back to you on the same page. It is not transmitted to this site, to its operator, or to any third party.

There is no account system, no database and no server-side processing of any kind. Nothing you paste is written to any storage, including your browser's own local storage. Closing or reloading the page discards it entirely.

What the web host can see

This site is a set of static files served by Netlify. Like any web server, Netlify receives a standard request when your browser loads the page, and that request includes your IP address, the page requested, the time, and your browser's user agent string. Netlify processes this information to deliver the site and for security and abuse prevention, under its own privacy terms.

This applies only to loading the page itself. Nothing you type or paste into the tool is part of any request, because the tool makes no requests at all once it has loaded.

Cookies and tracking

This site sets no cookies. It uses no tracking pixels, no advertising networks and no third-party scripts of any kind. It loads no external fonts, images or code. Every file the page needs is served from this site.

Counting visits

The web server keeps a simple count of how many times each page has been requested. This happens on the server, as part of serving the page. There is no analytics script, no beacon and no additional request from your browser.

What is recorded is a date, which page was requested, and whether the request identified itself as an automated crawler. Nothing else. No IP addresses are stored, no browser or device information is stored, no cookie or identifier is set or read, and nothing is recorded that could distinguish one visitor from another or link two visits together.

The text you paste into the tool is never part of this, and never could be: it is not sent to the server at any point.

Personal information

No personal information is collected, because there is no mechanism on this site capable of collecting any. There is no form to complete, nothing to sign up for, and no identifier assigned to visitors.

If you send an email to the contact address below, that email and its contents are received in the normal way and retained only for as long as needed to respond.

Children

This site is not directed at children and collects no information from any visitor, regardless of age.

Changes

If this policy changes, the revised version will be published on this page with an updated date. Any change that affected how the tool handled pasted text would be stated prominently on the home page, not only here.

Contact

Questions about this policy can be sent to hello@withmagic.ai.
